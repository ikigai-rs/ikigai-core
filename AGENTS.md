# AGENTS.md

`ikigai-core` is the ikigai resolution kernel (resources, verbs, representations, caching,
capabilities) and the vocabulary it describes itself with.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text.
- Security reports go through [private vulnerability
  reporting](https://github.com/ikigai-rs/ikigai-core/security/advisories/new), never a public
  issue.
- Use American spelling (behavior, color, labeled, artifact).
